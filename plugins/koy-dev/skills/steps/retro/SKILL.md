# retro

시작할 때 이 skill의 기준 폴더에서 세 단계 위(koy-dev plugin 루트)의 `reference/koy-config-usage.md`를 읽고 따른다.

작업 결과가 아니라 **작업 환경**을 고친다. 다음 작업에서 같은 실수가 나지 않게 하는 것이 목적이다.

## 1. 원천 읽기

- 돌아볼 세션의 기록. 지정이 없으면 현재 세션.
- 그 작업의 `<산출물 위치>/<slug>/` 결과물. 특히 `flow-state.md`, `ready-report.md`
- 이 프로젝트의 `.claude/koy-config.md`, `CLAUDE.md`
- `<산출물 위치>/koy-feedback.md`. 이 프로젝트에서 지금까지 쌓인 지표와 문제점이다. 없으면 새로 만든다.

## 2. 사용 지표

작업 하나에 한 줄을 남긴다. 기록에서 확인되는 값과 세션을 읽고 추정한 값을 구분한다.

| 지표 | 원천 | 구분 |
| --- | --- | --- |
| 흐름, slug | flow-state.md | 기록 |
| 소요 시간 (단계별, 전체) | flow-state.md의 시작·끝 시각 | 기록 |
| ready 실행 횟수, 실패 횟수 | flow-state.md의 「ready 기록」 | 기록 |
| ready 통과 후 커밋 전 추가 수정 | git 기록과 세션 | 기록 |
| 사용자가 다시 설명하거나 방향을 바로잡은 횟수 | 세션 | 추정 |

## 3. 문제점 찾기

세션에서 이런 순간을 찾는다.

- 에이전트가 같은 실수를 반복했다
- 필요한 정보를 찾는 데 오래 걸렸거나 끝내 못 찾았다
- skill이 지시한 단계가 이 프로젝트에 맞지 않았다 (없는 대상을 찾았다, 불필요한 질문을 했다)
- 사용자가 끼어들어 방향을 바로잡았다
- 자동 검사가 잡을 수 있었던 실수가 ready까지 갔다

## 4. 고칠 곳 정하기

문제마다 고칠 곳을 하나 고른다.

| 고칠 곳 | 기준 |
| --- | --- |
| **자동 검사** (lint 규칙, 타입, 테스트, pre-commit, CI) | 정해진 패턴으로 잡을 수 있는 기계적인 실수. 규칙 문장보다 검사를 먼저 고려한다. 이미 있는데 연결이 안 된 검사가 있는지 먼저 본다 |
| **koy-config** (`.claude/koy-config.md`) | 이 프로젝트에서만 맞는 것: 대조 대상, 체크리스트, 명령어, 연결·겹침 결정. 저장소 skill이 바뀐 탓이면 `/koy-dev:sync`를 안내한다 |
| **CLAUDE.md** | 이 프로젝트에서 계속 지킬 규칙. 판단이 필요해서 자동 검사로는 안 되는 것만 |
| **koy 공통 skill** | 어느 프로젝트에서나 맞는 것: 단계 순서, 원칙, 완료 기준, 질문 방식 |

## 5. koy-feedback.md 갱신

`<산출물 위치>/koy-feedback.md`에 쓴다. 기존 내용 아래에 이어 쓴다.

```markdown
# koy 사용 기록

## 사용 지표
| 날짜 | 흐름 | slug | 소요 | ready 실행/실패 | 통과 후 재수정 | 바로잡은 횟수 (추정) |
| --- | --- | --- | --- | --- | --- | --- |

## 문제점과 개선 제안
### [날짜] <문제 한 줄>
- 근거: <세션에서 일어난 일>
- 고칠 곳: <자동 검사 | koy-config | CLAUDE.md | koy 공통 skill>
- 제안: <추가·수정할 문장이나 검사>
- 상태: <제안 | 반영 | 이슈 등록>
```

같은 문제가 이전 기록에 이미 있으면 새로 쓰지 않고, 그 항목에 이번 근거를 덧붙인다. 반복되는 문제가 가장 먼저 고칠 대상이다.

## 6. 제안과 반영

심각한 순서로 보여준다. 반복된 문제를 위에 둔다. 사용자가 고른 항목만 반영한다.

- **자동 검사, koy-config, CLAUDE.md:** 이 프로젝트에서 바로 고치고, 상태를 "반영"으로 바꾼다.
- **koy 공통 skill:** 직접 고치지 않는다. koy 저장소에 올릴 **이슈 초안**을 만든다 (제목, 문제, 근거, 제안하는 수정). 사용자가 올리면 상태를 "이슈 등록"으로 바꾼다.
