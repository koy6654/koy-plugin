# ORIGIN

koy의 일부 skill은 아래 오픈소스 프로젝트의 내용을 바탕으로 고쳐 썼다. 원본은 모두 MIT License이며, 라이선스 조건에 따라 저작권 표시와 허가 문구를 아래에 그대로 둔다.

| koy skill | 바탕으로 한 원본 |
| --- | --- |
| `grill` | mattpocock/skills `skills/productivity/grilling` |
| `split` | mattpocock/skills `skills/engineering/to-tickets` |
| `diagnose` | mattpocock/skills `skills/engineering/diagnosing-bugs` |
| `retro` | mattpocock/skills `skills/engineering/retro` |
| `implement` (실제 결과물로 증명, 데이터 형태 먼저, 작은 단위로 진행) | cursor/plugins `pstack/skills/principle-prove-it-works`, `principle-model-the-domain`, `principle-sequence-verifiable-units` |

원본이 갱신되어도 koy에는 자동으로 반영되지 않는다. 필요하면 원본을 보고 손으로 반영한다.

- mattpocock/skills: https://github.com/mattpocock/skills
- cursor/plugins (pstack): https://github.com/cursor/plugins/tree/main/pstack
